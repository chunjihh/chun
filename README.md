# 📢 Ecoblog (Pi Network Community App)

**"Your Direct Gateway to Pi News"**

## 📖 About The Project
Ecoblog is a lightweight, serverless web application built for the Pi Network ecosystem. It serves as an ecosystem bridge, delivering the latest official Pi Network blog news straight to the Pioneer's screen. 

By utilizing the `rss2json` API, it fetches the newest updates seamlessly while strictly complying with Pi Network's copyright guidelines by directing users to the official source.

## ✨ Features
- **Real-time Updates:** Automatically fetches the latest posts from the official Pi Network blog.
- **Serverless Architecture:** 100% frontend-based (HTML/CSS/JS) for lightning-fast rendering and zero server costs.
- **Pi Browser Ready:** Integrated with Pi SDK (`sandbox` ready) for seamless ecosystem expansion.
- **Copyright Compliant:** Displays only dates and titles. All clicks redirect safely to the official `minepi.com` blog.

## 🛠 Tech Stack
| Category | Programming Language / Framework |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript (jQuery) |
| **API / Integration** | REST API (rss2json), Pi Network SDK |

## 🚀 How to Run
Since this project is entirely frontend-based, no complex server setup is required.
1. Clone or download this repository.
2. Open the `index.html` file in any web browser.
3. (Optional) Host it directly via GitHub Pages to access it from the Pi Browser.
